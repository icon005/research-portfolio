# Chinedu Alamezie Research Portfolio

Static academic portfolio for Chinedu Charles Alamezie, covering methane hydrate growth, transport modelling, flow assurance, publications, and ongoing projects.

## Updating the site

- Edit `index.html` to update publications, projects, profile text, and links.
- Edit `styles.css` to adjust the design.
- Store optimized background images in `images/`.

GitHub Pages can publish the repository directly from the `main` branch.
